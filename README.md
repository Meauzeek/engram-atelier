# 图录工坊 · Engram Atelier v5

适配手机、平板与桌面的 CYOA 编辑器。纯静态前端，无构建依赖和后端；可放到 GitHub Pages，或在电脑上使用单文件 HTML。项目数据保存在当前浏览器，支持完整工程导入导出、历史快照、另存为、Markdown 同步及 PNG 图件导出。

**部署文件已准备好；这个压缩包本身不代表 GitHub 仓库或网站已经发布。**

## 首次使用

GitHub Pages 发布入口是根目录 `index.html`。具体步骤见 `DEPLOY_GITHUB.md`。

不部署时，电脑可以直接打开下列任一单文件。手机长期使用请优先打开部署后的 HTTPS 地址，而不是文件管理器的 HTML 预览。

| 文件 | 内容 |
| --- | --- |
| `index.html` | 部署入口，带离线程序与主屏幕安装支持。内置三种新建模板。 |
| `Stellagram_CYOA_Default_Demo_v5.html` | 随星录预填版：10 个模块、61 个选项，初始 50 铟锭 / IN。 |
| `Stellagram_CYOA_Studio_v5.html` | 随星录留白框架：9 个模块、45 个待填选项，初始 0 IN，可全部修改。 |
| `Generic_CYOA_Studio_v5.html` | 通用空白编辑器：无预设模块，文字标题或自定义 Logo。 |
| `templates/*.json` / `*.js` | 可以导入编辑器的完整模板数据。 |
| `templates/*.md` | 对应模板的可读内容，适合讨论文案。 |

部署版首次进入显示随星录预填版。在“存档 / 项目库 → 新建”可以选择预填版或通用模板。以后重新打开，同一浏览器会优先恢复已有进度，不会因为模板更新自动重置项目。

## 手机、平板与桌面

手机底部保留“目录、编辑、试玩、存档”四个入口。点卡片后打开底部编辑面板，使用“完成编辑”收起；右上角“⋯”提供项目与外观、导出、导入、另存为等操作。平板按实际可用宽度调整列数，侧栏按需展开。桌面仍保留目录与五列画布。

说明文字默认 **20 px**，选项标题 **28 px**，模块标题 **36 px**，卡片间距 **24 px**。表单和触摸按钮也已放大。手机端不强制把五张卡挤进一行；最终图片的导出宽度和列数独立配置，可以继续导出五列。

窄屏点击“编辑”会编辑当前对象；点击封面或项目设置可修改整体文案。在手机上不用按住 Shift/Ctrl：前置、互斥及解锁条件改成可搜索的复选列表。

## 通用模板、自定义 Logo

入口：**项目与外观 → 文字标题与自定义 Logo**。

支持文字标题、上传自己的 Logo、随星录文字 Logo 和按项目名称识别四种模式。自定义模式可上传“浅色界面 Logo”和“深色界面 Logo”，设置对齐与最大宽度，并决定是否显示副标题。只上传一张时，两种主题都能使用；未上传时回退到文字标题。推荐透明 PNG，也支持 JPEG、WebP、GIF 静态帧。

Logo 使用现有图片处理器写进工程，与选项插图一样可通过 JSON/JS 回读。“MD＋图片包”会额外输出两套 Logo 文件，方便交流。改变文字标题不会修改原 PNG 中的字形；需要换字时请选择文字标题或另上传图片。

通用模板不会强制使用《随星录》Logo、人物、模块或铟锭。随星录模板沿用黑白文字 Logo、双色四宫格封面装饰、左上 E 形工坊标志及紫绿主色。

## 做旧、配色与字体

**项目与外观 → 版式、字体与配色**：做旧强度范围 0–40，默认 **0 / 关闭**。可拖动滑块或直接选择“关闭、轻微、适中”。纸纹不模糊文字。透视网格与斜向底纹另有独立开关；关闭做旧不会自动关闭这些几何背景。

紫、绿、灰调钴蓝与珊瑚粉仍可分别修改；字号、卡距、背景、圆角和图片占位也能修改。旧项目导入时保留自己的样式；“套用协调配色与排版”只更新外观，不重写内容、价格、规则，也不强行更换做旧强度。

英文和数字优先 Rajdhani，汉字优先明体／宋体，继续保留中英分工。**工程包不附带字库**。联网时尝试读取 Google Fonts；未成功加载时使用本机字体。字体选择窗口支持读取自己已有的英文字重和中文字库，存在本机独立字体缓存中，不写入 JS/JSON/HTML 工程。首次断网前没有加载过的字体，不能凭空离线出现；可手动选择本机字库获得更确定的显示与 PNG 字形。

字体服务只接收字体请求，不接收项目内容。PNG 为栅格化图像；SVG 不内嵌用户选择的字库。

## 进度如何保存

### 本机项目库

文字、图片、Logo、模块、条件、主题和试玩记录都属于项目数据。停止编辑约半秒后提交自动保存；界面显示待保存、已保存或失败状态。数据库不可用时尝试较小的备用存储；仍失败会明确要求导出，不把失败写成成功。

“存档 / 项目库”可以新建、重新读取、切换、保留为分支和删除非当前项目。导入或新建之前，会尝试保存当前内容；有未解决的失败时，不悄悄丢掉草稿。原有 v4 存档依然可读。

数据库主副本、活动项目记录和版本号通过事务保存。同一来源的另一标签页修改了同一项目时，会检查版本号并暂停覆盖；可以读取较新版本，或把当前草稿保存为分支。它防止同一浏览器内的误覆盖，**不等于多设备协同编辑或云端合并**。

项目按部署路径隔离。独立 HTML 文件、不同仓库路径、不同域名、不同浏览器和设备并不自动共享项目库；从 v4 本地文件转到 Pages 时，应先导出完整存档再导入。

### 历史快照

提供手动“保存当前快照”，并在持续创作中定期保留之前提交的版本。每个项目最多保留 12 份历史；大体积图片项目会更早回收较旧快照。恢复快照会新建分支，保留原项目。

另有用于小型未提交草稿的应急日志，但它受备用存储大小限制，不能保证恢复强制关闭瞬间的每一个字。关闭浏览器前等保存状态完成，重要阶段另存完整工程。

### 备份与跨设备转移

在“存档 / 项目库”点击 **备份 / 跨设备转移**，生成包含图片的完整 JSON。支持文件分享的浏览器会打开系统分享面板；否则下载文件。把文件放进自己的文件空间或发送到另一设备，在另一设备的工坊中“导入存档”即可。

JS/JSON 才是完整可回读数据。Markdown 供阅读与讨论，不承担完整恢复功能。“MD＋图片包”包含可读文本、图片和完整工程。

**这一版没有自动云同步、账号服务、GitHub Token 输入框或后台上传。** GitHub Pages 发布的是编辑器与随包模板，日常修改只存本机；不要把私人存档另行上传到公开仓库。

浏览器存储不是永久保险。可以在项目库展开“备份与离线使用”，请求持久存储并查看使用量；是否批准取决于浏览器。清除网站数据、卸载或换设备等情况仍需要外部备份。历史快照与主副本位于同一设备，不能抵御一起被清理。避免无痕模式创作。[S2]

## 另存为

支持自定义文件名和 JS、JSON、HTML、MD 四种格式。可选择生成独立项目副本；副本会获得新项目 ID，原模块和卡片引用保持一致。

具备相应文件访问能力的环境可选择保存位置并关联文件；否则退回下载。`Ctrl/Cmd+S` 保存已关联文件，`Ctrl/Cmd+Shift+S` 打开另存为。关联授权不写入存档。手机优先使用 JSON 分享／下载，不依赖桌面的磁盘覆盖接口。

另存为 HTML 会封装可编辑单文件。它不注册部署版离线程序，项目库按该文件路径隔离；需要 PWA 时继续使用部署根目录的 `index.html`。

## 图件和标题

保留长图 PNG、阅读分页、分段裁剪、逐模块图件 ZIP 和 SVG。图片生成在当前设备进行，不上传服务器。手机触摸环境默认低倍率阅读分页；图件准备完成后出现“保存文件 / 系统分享”，避免在长时间渲染后丢失下载手势。

手机内存有限，优先 1080 px、1×、正常比例分页。长图超过保守画布阈值时分段，不静默截掉末尾。极长的单卡会使用续页，局部版式可能简化。

默认图位 1:1，标题、说明字号分开。模块标题、数字、英文副标题、选择提示和卡片编号可独立隐藏；独立展示标题行可居中或左右对齐，且不参与计分。导出图件保持这些设置。

SVG 使用浏览器 `foreignObject`，不保证所有矢量编辑器兼容。PNG 更适合直接发送和查看。

## PWA、离线与更新

部署到 HTTPS 后，工坊会缓存自身程序；“⋯ → 离线 / 安装”显示就绪状态。只有首次完整加载并成功准备离线程序后，才具备离线重新打开的条件。离线程序与项目库是两套存储：更新程序不主动清空项目。

Android 可从浏览器菜单安装或添加到主屏幕；iPhone 使用 Safari 的分享菜单 → 添加到主屏幕，系统提供该项时开启“作为网页 App 打开”。不同设备菜单名称可能稍有差异。[S3]

有新版本时提示更新，不在正在编辑时自动强制刷新。点击“保存并更新应用”会先提交当前草稿；保存失败会停止更新。外部字体只在成功载入后才可能离线复用。

Service Worker 缓存范围仅限本仓库路径，不接管 QUALITHM 或其他仓库路径，不把未知 HTML、MD 或工程文件误替换为工坊首页。

## 修改源码后

日常填写不用构建。只有修改了应用代码或要更新随包模板时，才运行：

```bash
# 仅在修改 templates/*.json 后需要 Node.js 这一步
node tools/sync_templates.cjs

# 生成三个离线单文件（Python 3，无第三方依赖）
python tools/build.py

# 最后更新离线程序的内容哈希，发布时必须一起上传 sw.js
python tools/update_sw.py
```

模板数据仍沿用 `engram-cyoa` schema version 1。应用版本 v5 与存档结构版本不同，不要求用户改存档版本号。

## 验证范围与限制

真实 Chromium DOM 中检查了 320、390、600、768、820、1024、1366、1440 CSS px 窗口；涵盖手机面板、五列桌面、Logo 上传、JS/MD、规则解锁、做旧开关、存档冲突与分支。30 项回归检查通过，无页面脚本异常；另外通过 14 项 Service Worker 路由与缓存生命周期单元检查，及原生 SVG → Canvas → PNG 输出检查。

测试环境对浏览器访问 HTTP 源和本机数据库有限制，因此回归测试使用**仅测试用的内存 IndexedDB 适配器**，不是 iOS/Android 真机存储；Service Worker 测试也使用模拟缓存与网络。原生安装流程、实际断网重启、系统分享、原生文件对话框和设备重启后的持久保存，尚未完成端到端真机验证。相关报告见 `tests/`，测试适配器不进入运行入口。
